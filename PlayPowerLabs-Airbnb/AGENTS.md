# Project Agent Guide

## Scope

This repository is a React and Vite Airbnb listing clone. Keep UI changes focused, preserve existing visual conventions, and validate changes with `npm run build`.

## Interaction requirements

- Keep Photo Tour and Lightbox keyboard accessible.
- Use semantic buttons and labels for controls.
- Preserve focus when opening and closing overlays.
- Keep desktop fidelity as the primary target for the take-home task.

## Validation

Run `npm run build` after implementation changes. Run `npm run lint` before submission and review any warnings that are unrelated to the changed slice.
